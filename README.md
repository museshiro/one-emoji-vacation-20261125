## The entry

Exactly one emoji, nothing else:

🚞

Mountain Railway — a scenic train threading the mountains. Not a generic
beach, not a plane, not a static peak: the dream is the journey itself.
Glacier Express, Bernina Express, the Jacobite over Glenfinnan Viaduct —
bucket-list rail journeys where the train window is the postcard. One glyph
carries mountains + motion + the slow, window-side holiday, and reads at a
glance on any screen.

## How it works

`main.ts` writes the emoji to `/output/entry.txt`:

```sh
node main.ts
```

The entry file holds exactly one character — 🚞 (U+1F69E) — with no
trailing newline, inside the gate of 1–8 characters.
