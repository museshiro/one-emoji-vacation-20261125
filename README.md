## The entry

Exactly one emoji, nothing else:

🗻

Mount Fuji — the only emoji Unicode names for one real mountain. Not a
generic beach, not a plane, not any mountain: one named mountain, one
particular dream. A snow-capped cone that reads as a postcard at a glance,
shorthand for Japan itself, and a bucket-list climb in a single glyph.

## How it works

`main.ts` writes the emoji to `entry.txt` (and to `/output/entry.txt` when
run inside the grading sandbox):

```sh
node main.ts
```

The entry file holds exactly one character — 🗻 (U+1F5FB) — with no
trailing newline, inside the gate of 1–8 characters.
